Update review: 101 updates, and the ones that will bite

Every mod with a newer 1.21.1 NeoForge build, what changed, what it requires, and where it collides with the rest of the pack. Generated from a packwiz update --all run in a scratch copy.

Applied on 2026-11-08. The 54 Routine mods were upgraded in the pack. This page is the pre-upgrade review; the Care, Danger and Manual groups list what is still open.
Read the danger and care groups before touching the safe one. A blanket update moves Iris to a build that requires a Sodium you deliberately pinned, re-applies the Regions Unexplored upgrade you reverted, and pulls an alpha C2ME. Terralith 2.6.2 exists but packwiz will not offer it, so it needs a manual metadata edit. The safe group has been applied.

Notable changes

The entries worth knowing about before you decide. Everything else is patch noise or bug fixes.

Iris 1.8.14 is a Sodium 0.8 build

Its only changelog line is "Updates to Sodium 0.8". It hard-requires Sodium 0.8.13, the version you rolled back in May.

iris sodium

Sodium 0.8.13 adds a graphics options API

Also a clearer crash message when NeoForge keeps loading after a severe error, a buffer overflow fix in Kernel32.getModuleFileName, and correct atomic operations on native buffers.

sodium

MineColonies 1.1.1418 needs its siblings

The release notes require Structurize 1.0.837+, MultiPiston 1.2.51+, BlockUI 1.0.199+ and Domum Ornamentum 1.0.223+. The update set satisfies all four; Multi-Piston stays at 1.2.58. The only listed change is improved item transfer.

minecolonies structurize blockui domum-ornamentum multi-piston

Structurize and BlockUI are bug fixes

Structurize fixes an NPE with gravity over non-solid blocks. BlockUI fixes a ConcurrentModificationException in view draw loops.

structurize blockui

Blueprint 8.2.0 changes worldgen internals

Faster modded biome slices, an event for modifying slices before dimension assignment, and resource streams that are no longer single-use.

blueprint

Supplementaries 4.0.2 and Moonlight 3.8.2

Supplementaries adds polytone colored-light compat and fixes a dupe with the pully. Moonlight adds plugin registration, which Every Compat needs.

supplementaries moonlight

Open Parties and Claims 0.33.0 reworks the config

New player config screen with search and categories, new permission nodes (claiming_paused, new_forceloads_paused), a "Can Claim Next To" option, and a fix for single-chunk anchoring.

open-parties-and-claims

Sable 2.0.6 fixes fluid-standing entities

Striders and similar entities no longer break when standing on fluids. Fabric networking mixins were also adjusted.

sable

Slice and Dice 4.3.4 fixes a server crash

Sprinklers on contraptions no longer crash the server, and potion sprinklers work reliably.

slice-and-dice

Lithium 0.15.4 is a small fix batch

Fixes a supporting-block movement VoxelShape offset, double inventory invalidation, and a crash when modded levels have broken registries.

lithium

Connector beta.17 adds Class Tweakers

Adapter bumps, provided-namespace resolution for Fabric fluid types, and the cache moves out of the mods folder.

connector forgified-fabric-api

Simple Voice Chat 2.6.27 hardens the protocol

Invalid data no longer disconnects clients, oversized packets are logged, and the API can skip a packet via ProtocolException.

simple-voice-chat

Terralith 2.6.2 backports 2.6.0

Now depends on Lithostitched, adds a config file, two new world types, and warns about uninstallation. packwiz will not offer it.

terralith lithostitched

Lithostitched 1.8.1 adds worldgen targeting types

New any, regex, biome/climate and biome/has_feature targets for modifiers, plus fixes for processor-list injections.

lithostitched

Let Me Despawn fixes an Easy NPC crash

Mobs created by other mods no longer throw an NPE during spawn. Requires Almanac 1.26.11.1.

lmd almanac

Sophisticated Core 1.5.31 fixes inventory accounting

Compression upgrades stop claiming extra slots, cooking upgrades handle input-aware recipes, and JEI transfers no longer kick players when JEI is missing server-side.

sophisticated-core

Create Dragons Plus 1.11.9

Grouped Ponder cards with animated cycling, and a loot-table fix for fragile fluid tanks when Simulated is absent.

create-dragons-plus

C2ME 0.4.0 alpha has no release notes

Builds are auto-uploaded by CI. The one listed commit adds ChunkTicketLevelUpdatedEvent. That is not enough evidence to put an alpha chunk engine on a live world.

c2me-neoforge
